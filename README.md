## Featured Open Source (MIT)

- **[Agent Workbench (`local-agent-workbench`)](https://github.com/jamesarslan/local-agent-workbench)** ([Project Site](https://jamesarslan.github.io/local-agent-workbench/) · [Guide & FAQ](https://jamesarslan.com/agent-workbench) · [Releases](https://github.com/jamesarslan/local-agent-workbench/releases) · [Discussions](https://github.com/jamesarslan/local-agent-workbench/discussions)): Free, MIT-licensed desktop app (Electron + Python) that pairs a model source (managed `llama.cpp`/Strata, running Ollama/LM Studio/vLLM servers, Linux or Windows GPU boxes over plain SSH, or hosted APIs) with six coding-agent CLIs (`OMP`, `Pi`, `Claude Code`, `Codex`, `Hermes`, `opencode`) per project folder — with copyable run summaries, portable `.agent-workbench/profiles.json` settings, `AGENTS.md` project setup, 8 MIT starter kits (including Blender & Roblox Studio MCP), embedded terminal dock, and zero telemetry.
- **[local-ai-coding-setup](https://github.com/jamesarslan/local-ai-coding-setup)**: local LLM coding setup, document extraction pipeline notes and inference benchmarks on an RTX 5090, using `llama.cpp`, TurboQuant KV-cache compression, OpenCode and MCP tooling.
- **[deskbridge-public](https://github.com/jamesarslan/deskbridge-public)**: MIT-licensed open-source keyboard, mouse and clipboard sharing for Windows and Fedora/Linux, built on Deskflow.
- **[ai-memory-system](https://github.com/jamesarslan/ai-memory-system)** *(experimental)*: conversation compression, Gemini embeddings and semantic retrieval for AI assistants.
